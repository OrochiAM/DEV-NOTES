Client i Server Komponente

Client: 
Samo u browseru se runuje kod.
Startuje fetch request tek kad se mountuju komponente.
Mora da se koristi useEffect i useState.

Server: 
Kod se runuje na serveru.
Fetchovanje moze pre rendera da se izvrsi.
Nepotrebni useEffect i useState.

Primer:
export default async function PostsPage() {
  const res = await fetch("https://jsonplaceholder.typicode.com/posts")
  const data = await res.json()
  return (
    <pre>
      {JSON.stringify(data, null, 2)}
    </pre>
  )
}
